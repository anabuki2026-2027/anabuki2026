# E チーム（デザイン）

[← チーム別ガイドにもどる](README.md)

## ひとことで

**アプリの「見た目」を作るチームです。**
色・文字の大きさ・配置・画像などを、CSS と画像ファイルで整えます。
C チームが作った画面（HTML）に、見た目を付けていきます。

> **C チームとのちがい**
> C は「画面に何を、どの順番で並べるか（HTML）」を作ります。
> E は「それをどんな色・大きさ・配置で見せるか（CSS・画像）」を作ります。

---

## さわるファイル・フォルダ

| ファイル・フォルダ | 何をするもの？ |
| --- | --- |
| `webroot/css/` | 見た目を決める CSS ファイルを置く。**自分たちの CSS はここに新しく作る**。 |
| `webroot/img/` | 画像を置く。 |
| `webroot/font/` | 文字のデザイン（フォント）を置く。 |
| `webroot/favicon.ico` | ブラウザのタブに出る小さなアイコン。 |
| `templates/layout/default.php` | すべてのページの「外わく」。CSS の読み込みもここ。**C チームと協力**。 |
| `templates/element/flash/` | 「保存しました」などのメッセージの見た目。**C チームと協力**。 |
| `webroot/js/` | 画面の動き（アニメーションなど）。**C チームと協力**。 |

さわらないファイル：

| ファイル | 理由 |
| --- | --- |
| `webroot/css/normalize.min.css`、`milligram.min.css` | 他の人が作った部品。直接変えずに、自分たちの CSS で上書きする。 |
| `webroot/css/cake.css`、`home.css` | CakePHP の最初の見た目。いずれ使わなくなる。 |

## 作業の流れ

### 1. 自分たちの CSS ファイルを作る

`webroot/css/style.css` を新しく作ります。

### 2. CSS を読み込ませる

`templates/layout/default.php` の中に、CSS を読み込んでいる行があります。
その最後に `'style'` を足します（C チームに声をかけてから変えてください）。

**変える前**

```php
<?= $this->Html->css(['normalize.min', 'milligram.min', 'fonts', 'cake']) ?>
```

**変えたあと**

```php
<?= $this->Html->css(['normalize.min', 'milligram.min', 'fonts', 'cake', 'style']) ?>
```

> 一番最後に読み込んだ CSS が優先されます。
> だから `style.css` を最後にすると、もとからある見た目を自分たちのデザインで上書きできます。

### 3. C チームと class の名前を決める

CSS で見た目を付けるには、HTML に `class` の名前が必要です。
C チームと「この部分は `user-list` という名前にする」のように決めておきます。

```css
.user-list {
    background-color: #f5f5f5;
    padding: 16px;
}
```

### 4. 画像を使う

1. 画像を `webroot/img/` に入れます（例：`webroot/img/logo.png`）。
2. 画面に出すときは、C チームに次の書き方を伝えます。

```php
<?= $this->Html->image('logo.png', ['alt' => 'ロゴ']) ?>
```

CSS の中で画像を使うときは、`css` フォルダから見た場所を書きます。

```css
.header {
    background-image: url('../img/header.png');
}
```

### 5. 表示を確認する

```bash
bin/cake server
```

ブラウザで <http://localhost:8765> を開いて確認します。

> CSS を変えたのに画面が変わらないときは、ブラウザが古い CSS を覚えたままになっています。
> **`Ctrl + F5`** を押すと、最新の CSS で表示しなおせます。

## ほかのチームとのつながり

| チーム | やりとり |
| --- | --- |
| C（View） | **C と決める**：`class` の名前。外わく（layout）は一緒に作る。 |
| A（統括） | **A と決める**：アプリ全体の色や雰囲気。外部のフォント（Google Fonts など）を使いたいときも A に相談。 |
| G（テスト） | スマホの画面でくずれていないかなど、見た目のチェックをお願いする。 |

---

## 気をつけること

- **ファイルの名前は、英語の小文字と `-` だけ**にしてください（例：`main-visual.png`）。日本語やスペースが入っていると、表示されないことがあります。
- 画像のサイズが大きいと、ページの表示がおそくなります。なるべく小さく（軽く）してから入れてください。
- 人が作った画像やフォントを使うときは、**使ってよいもの（ライセンス）か**を必ず確認してください。
- `webroot/` に入れたファイルは、だれでも見られます。見られて困るものは置かないでください。
