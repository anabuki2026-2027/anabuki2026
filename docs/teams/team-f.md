# F チーム（DB）

[← チーム別ガイドにもどる](README.md)

## ひとことで

**データベースの「表」を作るチームです。**
会員や記事などのデータをしまっておく表を設計して、全員のパソコンに同じ表ができるようにします。
F チームが表を作らないと、B・D・C チームは作業を進められません。**一番最初に動くチーム**です。

> **B チームとのちがい**
> F は「名簿の用紙（表）」を作ります。
> B は「名簿に書きこんだり、名簿から探したりするプログラム」を作ります。

---

## さわるファイル・フォルダ

| ファイル・フォルダ | 何をするもの？ |
| --- | --- |
| `config/Migrations/` | **表を作る・変えるためのファイル**を入れる。今はまだないが、下のコマンドで自動で作られる。 |
| `config/Seeds/` | 最初から入れておくデータ（ためしの会員など）を書くファイルを入れる。これも自動で作られる。 |
| `config/app_local.php` | 自分のパソコンのデータベースにつなぐための設定（自分のぶんだけ）。 |

---

## なぜ phpMyAdmin で表を作ってはいけないの？

phpMyAdmin で表を作ると、**自分のパソコンにしか表ができません。**
ほかの人のパソコンには表がないので、アプリが動かなくなります。

そこで、「表の作り方」を**ファイル（マイグレーション）**に書いて GitHub で共有します。
みんながそのファイルを実行すれば、全員のパソコンに同じ表ができます。

```text
F チーム：表の作り方をファイルに書く → GitHub にプッシュ
                                          ↓
全員   ：git pull → bin/cake migrations migrate → 自分のパソコンにも同じ表ができる
```

> phpMyAdmin は、**表がちゃんとできたかを見る**ためだけに使ってください。

## 作業の流れ

### 1. 表を設計する

A チームと相談して、表の名前と項目を決め、B・D・C チームに共有します。

| 項目 | 種類 | 意味 |
| --- | --- | --- |
| `id` | 数字 | 番号（自動で付く） |
| `name` | 文字（短い） | 名前 |
| `email` | 文字（短い） | メールアドレス（ほかの人と同じはダメ） |
| `password` | 文字（短い） | パスワード |
| `created` | 日時 | 作った日時（自動で入る） |
| `modified` | 日時 | 最後に変えた日時（自動で入る） |

### 2. マイグレーションのファイルを作る

```bash
bin/cake bake migration CreateUsers name:string email:string:unique password:string created modified
```

- `CreateUsers` は「users の表を作る」という意味の名前です。
- `id` は書かなくても自動で作られます。
- `created` と `modified` は、日時が自動で入る特別な項目です。

`config/Migrations/` に、`20261022123456_CreateUsers.php` のような名前のファイルができます。
中を開いて、項目がまちがっていないか確認してください。

### 3. 自分のパソコンで表を作る

```bash
bin/cake migrations migrate
```

phpMyAdmin を開いて、`users` の表ができていることを確認します。

### 4. プッシュして、全員に知らせる

プルリクエストがマージされたら、A チームから全員に「`bin/cake migrations migrate` してね」と連絡してもらいます。

---

## 表をあとから変えるとき

**一度マージしたマイグレーションのファイルは、書きかえないでください。**
ほかの人のパソコンでは、もう実行ずみなので、書きかえても反映されません。

かわりに、「変える」ための新しいファイルを作ります。

```bash
bin/cake bake migration AddAgeToUsers age:integer
bin/cake migrations migrate
```

`AddAgeToUsers` は「users の表に age（年齢）を足す」という意味の名前です。

---

## ためしのデータを入れる（Seed）

画面を作るときに、データが 1 件もないと確認しづらいので、ためしのデータを用意します。

```bash
bin/cake bake seed Users
```

`config/Seeds/UsersSeed.php` ができるので、入れたいデータを書きます。
書いたら、次のコマンドでデータベースに入れます。

```bash
bin/cake seeds run
```

---

## よく使うコマンド

| コマンド | 何が起きる？ |
| --- | --- |
| `bin/cake bake migration CreateUsers ○○` | 表を作るファイルを自動で作る |
| `bin/cake bake migration AddAgeToUsers ○○` | 表に項目を足すファイルを自動で作る |
| `bin/cake migrations migrate` | まだ実行していないファイルを実行して、表を最新にする |
| `bin/cake migrations status` | どのファイルが実行ずみかを見る |
| `bin/cake migrations rollback` | 最後に実行したファイルを取り消す（**まだプッシュしていないとき**だけ使う） |
| `bin/cake bake seed Users` | ためしのデータを書くファイルを作る |
| `bin/cake seeds run` | ためしのデータをデータベースに入れる |

項目の種類の書き方：

| 書き方 | 種類 | 例 |
| --- | --- | --- |
| `string` | 短い文字（255 文字まで） | 名前、メールアドレス |
| `text` | 長い文字 | 記事の本文 |
| `integer` | 数字 | 年齢、個数 |
| `boolean` | はい / いいえ | 公開するかどうか |
| `datetime` | 日時 | 予約の日時 |
| `string:unique` | ほかと同じ値はダメ | メールアドレス |

## 名前の決まり

| もの | 決まり | 例 |
| --- | --- | --- |
| 表の名前 | 英語・**複数形**・小文字・単語の間は `_` | `users`、`blog_posts` |
| 項目の名前 | 英語・小文字・単語の間は `_` | `name`、`birth_day` |
| ほかの表とつなぐ項目 | つなぐ相手の**単数形** + `_id` | 記事を書いた会員 → `user_id` |

> 名前がずれると B・D・C チームのプログラムが動きません。[名前の決まり](README.md#全チーム共通名前の決まり)もあわせて確認してください。

## ほかのチームとのつながり

| チーム | やりとり |
| --- | --- |
| A（統括） | **A と決める**：どんな表を作るか。マージ後の全員への連絡をお願いする。 |
| B（Model） | **B にわたす**：表の名前と項目。表どうしのつながり（`user_id` など）。 |
| D・C | **D・C にわたす**：項目の名前（フォームの入力欄の名前になる）。 |
| G（テスト） | **G にわたす**：テストで使うためしのデータの形。 |
